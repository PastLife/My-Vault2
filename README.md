# My Vault — สมุดข้อมูลส่วนตัว

แอปเก็บข้อมูลสำคัญของตัวเอง (เอกสาร บัญชี รหัสผ่าน รูปบัตร) แบบ **เข้ารหัสทุกชิ้น**
ติดตั้งลงหน้าจอโฮมของมือถือได้ และใช้ได้แม้ไม่มีเน็ต

```
 รหัสผ่าน ─┐
          ├─▶ กุญแจข้อมูล ─▶ เข้ารหัสทุกรายการ + ทุกรูป ─▶ เก็บในเครื่อง (IndexedDB)
 รหัสกู้คืน ─┘
```

- ข้อมูลอยู่ในเครื่องที่ใช้เท่านั้น ไม่ส่งไปที่ไหน
- ลืมรหัสผ่าน → ใช้รหัสกู้คืน (ได้ตอนสร้างสมุด)
- **ลืมทั้งรหัสผ่านและรหัสกู้คืน → เปิดข้อมูลไม่ได้อีกเลย** (ตั้งใจให้เป็นแบบนี้)
- ล็อกเองเมื่อไม่ได้ใช้ 5 นาที หรือพับแอปเกิน 1 นาที

## ติดตั้งบน iPhone

1. เปิดลิงก์ของแอปด้วย **Safari**
2. แตะปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรชี้ขึ้น)
3. เลือก **เพิ่มไปยังหน้าจอโฮม** → **เพิ่ม**
4. เปิดแอปจากไอคอน **My Vault** บนหน้าจอโฮม

> ⚠️ ควรติดตั้งลงหน้าจอโฮมเสมอ ถ้าใช้ผ่าน Safari เฉยๆ แล้วไม่ได้เปิดนานเกิน 7 วัน iPhone อาจลบข้อมูลของเว็บทิ้ง
> และควรกด **ตั้งค่า → ส่งออกไฟล์สำรอง** เป็นระยะ แล้วเก็บไฟล์ไว้นอกมือถือ

บน Android (Chrome): เปิดลิงก์ → เมนู ⋮ → **ติดตั้งแอป**

## ขึ้นเว็บด้วย GitHub Pages (ฟรี)

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ไม่ต้องมี `node_modules/`)
2. ไปที่ **Settings → Pages**
3. ตรง **Build and deployment** เลือก Source: **Deploy from a branch**, Branch: **main**, โฟลเดอร์: **/ (root)** → **Save**
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

GitHub Pages มีแค่ตัวโปรแกรม ข้อมูลของคุณไม่เคยขึ้นไปบนเว็บ

### ออกเวอร์ชันใหม่

1. แก้โค้ด
2. ถ้าเพิ่มไฟล์ใหม่ ให้ใส่ชื่อไฟล์ในรายการ `ASSETS` ของ `sw.js` (เทสต์จะเตือนถ้าลืม)
3. เปลี่ยน `VERSION` ใน `sw.js` (เช่น `'v1'` → `'v2'`)
4. อัปโหลดขึ้น GitHub → ผู้ใช้จะเห็นแถบ **"มีเวอร์ชันใหม่ แตะเพื่ออัปเดต"**

## รันในเครื่อง (สำหรับพัฒนา)

```bash
python3 -m http.server 8080     # แล้วเปิด http://localhost:8080
```

ต้องเปิดผ่าน `http://localhost` หรือ `https://` เท่านั้น (เปิดไฟล์ตรงๆ แบบ `file://` จะใช้การเข้ารหัสไม่ได้)

## ทดสอบ

```bash
npm test                                         # เทสต์อัตโนมัติ (Node 20+)
python3 tests/e2e/shell_smoke.py http://localhost:8080/   # หน้าล็อก/ตั้งค่า ในเบราว์เซอร์จริง
python3 tests/e2e/vault_smoke.py http://localhost:8080/   # หน้าสมุด + รูป
python3 tests/e2e/pwa_smoke.py                            # ติดตั้งได้ / ออฟไลน์ / อัปเดตเวอร์ชัน
```

เทสต์ในเบราว์เซอร์ต้องมี Python Playwright (`pip install playwright && playwright install chromium`) และ Pillow

## โครงสร้าง

```
js/core/      ฐานร่วม: crypto (เข้ารหัส), store (ทางเดียวที่เข้าถึงข้อมูล), session (ล็อกอัตโนมัติ),
              images (ย่อรูป), storage/ (IndexedDB + ตัวในหน่วยความจำสำหรับเทสต์)
js/ui/        โครงหน้าจอ: หน้าต้อนรับ ล็อก ตั้งค่า แถบล่าง
js/modules/   โมดูล: vault (สมุด) — โมดูลเงินจะเพิ่มเป็น money/
```
